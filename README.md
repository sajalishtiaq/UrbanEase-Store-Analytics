# UrbanEase-Store-Analytics
An advanced **Store Analytics System** developed in C++ for the Object Oriented Programming course. Analyzes performance of 100 retail stores with clustering, forecasting, and visualization.

## Features

- Generate realistic data for 100 stores (products, sales, staff, managers)
- **K-Means Clustering** (Geographic + Performance-based)
- Sales forecasting with confidence intervals
- Performance reports (Top 10 & Bottom 5 stores)
- Monthly sales bar graph visualization
- Update store monthly costs
- File-based data persistence

## Technologies

- **Language**: C++
- **OOP Concepts**: Structures, Dynamic Memory, File Handling, Data Analysis
- **Algorithms**: K-Means Clustering, Forecasting
